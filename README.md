# GoldBot

GoldBot is an MT5 trading system for XAUUSD with a future backend, licensing,
and mobile-first web dashboards.

## Repository layout

- `mt5/` — MetaTrader 5 Expert Advisor
- `backend/` — backend API (planned)
- `web/` — client and admin web application (planned)
- `database/` — PostgreSQL schema and migrations (planned)
- `docs/` — architecture and operating documentation

Phase 1 implements the MT5 Bot Core. See [docs/phase-1-mt5-core.md](docs/phase-1-mt5-core.md).
